ShareYourSounds

이어폰은 폰에만 연결해 두고 PC 소리를 들으세요.
PC 소리가 블루투스로 폰에 와서 폰 소리와 함께 나옵니다.
인터넷이 없어도, 폰 화면이 꺼져도 계속 재생됩니다.

최신 버전 다운로드

PC: Windows · Linux (.msi / .exe / .AppImage / .deb)  ·  폰: Android 8.0 이상 (.apk)

사용 방법

1
앱 설치 PC에는 PC 앱을, 안드로이드 폰에는 .apk를 설치합니다.
2
공유 시작 PC 앱에서 "공유 시작"을 누르면 QR 코드가 표시됩니다.
3
폰에서 QR 스캔 폰 앱으로 QR을 한 번 찍으면 PC가 기록되고 바로 재생됩니다. QR에 실린 열쇠로 확인한 폰에만 소리를 잠가서 보냅니다.

기술 스택

React + TypeScript Rust · Tauri 2 Bluetooth LE Opus AES-256-GCM Windows / Linux PulseAudio · WASAPI Android (Kotlin)
