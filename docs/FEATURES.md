# 기능

PC 앱과 폰 앱이 하는 일과 그 값입니다. PC ↔ 폰 약속은 [PROTOCOL.md](PROTOCOL.md), 코덱은 [CODECS.md](CODECS.md).
코드 주석은 이 세 문서의 절 이름만 가리킵니다. 값을 바꾸면 이 문서와 코드 상수를 같이 바꿉니다.

## 소리 캡처

기본 출력 장치로 나가는 소리를 그대로 받습니다.

| OS | 방법 | 형식 |
|---|---|---|
| Linux | PulseAudio 기본 sink(`pactl get-default-sink`)의 `.monitor` | 48 kHz 스테레오 f32, 20ms(960프레임) 조각 |
| Windows | 기본 출력 장치의 WASAPI 루프백 (cpal에서 출력 장치에 입력 스트림을 엶) | 장치 형식 그대로 |

- 캡처 → 인코더 통로는 조각 64개(20ms 기준 약 1초)까지 쌓입니다. 늦은 쪽은 밀린 만큼 건너뜁니다.

## 인코딩

- 코덱은 실행 중에 바꿉니다. 바꾸면 다음 조각부터 새 코덱입니다. 코덱별 값은 [CODECS.md](CODECS.md).
- 인코딩은 한 번만 하고, 폰들이 결과를 나눠 받습니다 (통로 64개).
- 채널 맞추기: 스테레오 출력은 입력의 앞 두 채널(모노 입력이면 양쪽에 복사), 모노 출력은 모든 채널의 평균.
- 리샘플: 출력 샘플 하나 = 그 시간에 해당하는 입력 구간의 평균. 입력 샘플레이트가 바뀌면 처음부터 다시 셉니다.

## 공유

- 공유 시작 = 캡처·인코딩·BLE 송신([PROTOCOL.md](PROTOCOL.md))을 같이 켬. 끌 때는 폰에 중지를 알린 뒤 끔 ([PROTOCOL.md](PROTOCOL.md) "제어 메시지"). 창을 닫아도 같습니다.
- PC 번호·열쇠는 처음 실행할 때 만들어 설정 폴더에 저장합니다 ([PROTOCOL.md](PROTOCOL.md) "찾기"). PC 이름 = 컴퓨터 이름(hostname).
- 화면 없이 송신만: `cargo run --example send [코덱 번호]` (번호를 빼면 기본 코덱). 고정 PC 번호 `00c0ffee`, 열쇠 `11`×32, 이름 `send-example`로 링크를 출력하고 5초마다 청취자 수를 찍습니다.

## PC 화면

- 상태(공유 여부·청취자 수·QR 링크·PC 이름·코덱)를 1초마다 다시 읽습니다.
- 창 모양에 따라 셋 중 하나만 보입니다.

| 조건 | 배치 |
|---|---|
| 높이 < 220 또는 폭 < 280 | 상태 한 줄만 |
| 높이 > 폭 | 세로: 작은 헤더, QR·상태 카드, 설정 카드(PC 이름·코덱), 넓은 버튼 |
| 그 밖 | 가로: 가운데에 좁게, 위 큰 로고·제목·PC 이름, 아래 [QR \| 상태·코덱·버튼]. 아래 여백을 5vh 더 줘 살짝 위로 |

- 높이 < 480이면 로고·제목·PC 이름을 숨깁니다 (QR·상태·코덱·버튼은 남김).
- QR 자리는 공유가 꺼져 있어도 점선 칸으로 남깁니다.
- 상태 점: 회색 "공유 꺼짐" / 주황 깜빡임 "연결 기다리는 중..." / 초록 "폰 N대 연결됨" (N = 확인을 통과한 폰 수).
- 공유 버튼: 시작은 주황, 중지는 회색.
- 코덱 목록·주의 문구는 PC 코덱 정의에서 받습니다 ([CODECS.md](CODECS.md)). 고른 코덱에 주의 문구가 있으면 그 아래 한 줄. 선택 상자는 어두운 바탕에 ▼를 직접 그립니다.

## 업데이트

공유 중에 갑자기 재시작돼 소리가 끊기지 않게, 확인만 자동이고 설치는 버튼을 눌러야 합니다.

- PC: 켤 때 한 번 GitHub 최신 릴리스의 `latest.json`을 확인합니다 (tauri updater). 새 버전이 있으면 "새 버전 vX 업데이트" 한 줄. 누르면 공유 중지 → 받아 설치 → 다시 시작. 인터넷이 없으면 아무것도 보이지 않습니다.
- 폰: 켤 때 한 번 GitHub API의 최신 릴리스에서 `.apk`를 찾습니다. 버전은 점으로 나눈 숫자끼리 비교(`0.10.0` > `0.9.1`). 새 버전이 있으면 "새 버전 vX 설치" 버튼. 누르면 받아서 안드로이드 설치 확인 화면을 띄웁니다. 실패·취소는 짧은 알림. 연결 제한 10초, 읽기 제한 30초.

## 폰 찾기·연결

- 서비스 UUID로 거른 스캔(저지연). 1초 동안 광고를 모은 뒤 후보를 고르고 ([PROTOCOL.md](PROTOCOL.md) "찾기"), 후보가 없으면 1초 더 모읍니다. 마지막으로 통과한 PC가 보이면 기다리지 않고 바로 붙습니다.
- 블루투스가 꺼져 있거나 스캔이 실패하면 3초 뒤 다시. 연결이 끊기면 1초 뒤 다시 찾습니다.
- 연결하면 연결 우선순위를 높게 하고 MTU를 요청합니다 ([PROTOCOL.md](PROTOCOL.md) "연결").
- 재생 중에 다른 PC의 QR을 찍으면 그 PC로 갈아탑니다.
- 화면에 보이는 PC 이름: 기록의 이름, 없으면 `PC <번호>`.

## 재생

- 포그라운드 서비스(알림바에 상태와 정지 버튼) + 부분 wake lock이라 화면이 꺼져도 계속 재생합니다.
- 디코더는 패킷 헤더의 코덱 번호로 고르고, 번호가 바뀌면 바꿉니다. 샘플레이트·채널이 다르면 재생기도 새로 만듭니다. 모르는 번호이거나 디코더를 못 열면 [CODECS.md](CODECS.md)의 "모름" 문구.
- 지터 버퍼 (무선으로 불규칙하게 오는 조각을 잠깐 모았다가 일정하게 재생):

| 값 | 동작 |
|---|---|
| 시작 60ms | 이만큼 모이기 전엔 재생하지 않음. 다 비면 다시 60ms까지 기다림 (= 끊김 1회) |
| 목표 80ms | 1초 동안의 최저 수위가 이보다 높으면 넘친 만큼 버림 (= 버림) |
| 최대 200ms | 넘게 쌓이면 오래된 조각부터 바로 버림 (= 버림) |

- 버릴 때는 스테레오 L·R 짝이 깨지지 않게 채널 수의 배수로, 마지막 조각 하나는 남깁니다.
- 재생 장치(AudioTrack): 저지연 모드, 미디어 용도, 버퍼 40ms.
- 손실: 헤더 순번이 1~1000 건너뛰면 그만큼 손실로 셉니다.

## 알림음

- 확인 통과 = 올라가는 두 음(880 → 1320 Hz), 해제(끊김·정지) = 내려가는 두 음(1320 → 880 Hz).
- 한 음 90ms, 음량 0.3, 앞뒤 5ms에 걸쳐 커지고 작아짐 + 감쇠 e^(−30t). 44.1 kHz 모노.
- 미디어 소리라 이어폰으로 PC 소리와 같이 들리고 미디어 음량을 따릅니다. 서비스가 먼저 끝나도 끝까지 울립니다.

## 폰 화면

- 메인 화면: 제목, 안내, 비주얼라이저, QR 스캔, 듣기/정지, PC 연결 기록, 업데이트(있을 때), 상태, 재생 상세(개발 모드).
- PC 기록이 없으면 QR 스캔 버튼만 보입니다 (처음 연결은 QR로만). 듣기 버튼은 "마지막 PC(이름)로 듣기".
- QR: 앱 안 스캐너(ML Kit)로 찍거나, 폰 카메라로 찍으면 링크로 앱이 열립니다. 열쇠 없는 QR은 "PC 앱이 옛 버전이에요", 기록에 열쇠가 없는 PC는 "QR을 다시 찍어야 해요".
- 권한: Android 12+ `BLUETOOTH_SCAN`·`BLUETOOTH_CONNECT`, 11 이하 `ACCESS_FINE_LOCATION`, 13+ `POST_NOTIFICATIONS`.
- 비주얼라이저: 원 둘레의 막대 64개, 위부터 시계 방향으로 저음 → 고음. FFT 1024(Hann 창), 60 Hz~16 kHz를 로그 간격 대역으로, −60~0 dB → 0~1. 올라갈 땐 바로, 내려갈 땐 매 프레임 0.88배로 천천히. 0.2초 넘게 새 소리가 없으면 0. 화면이 보일 때만 계산합니다.
- PC 연결 기록 화면: 최근 순. 누르면 연결, 길게 누르면 이름 바꾸기·삭제.
- 개발 모드: 제목을 1초 간격 안에 7번 누르면 켜지고/꺼지며 앱을 다시 켜도 기억합니다. 켜면 재생 상세를 1초마다 보입니다: `코덱 번호 이름 · MTU · KB/s` / `버퍼 ms (+재생장치 ms) · 손실 · 끊김 · 버림 ms · 풀기 실패`.

## PC 기록

- PC 번호로 구별하고 이름은 표시용. 최근에 연결한 PC가 앞.
- QR을 찍으면: 없으면 추가, 있으면 열쇠를 새 값으로. 이름은 비어 있을 때만 QR 값으로 채웁니다 (사용자가 바꾼 이름 유지).
- 저장 형식: 한 줄에 PC 하나, `번호 \t 마지막 연결 시각 \t 열쇠 \t 이름` (이름의 탭·줄바꿈은 공백으로).
- 옛 형식 읽기: 5칸(`번호·시각·주소·열쇠·이름`)은 주소를 버림, 3칸(`번호·시각·이름`)은 열쇠 없이. 더 옛 버전이 "마지막 PC" 하나만 저장하던 값은 처음 읽을 때 기록으로 옮깁니다.
